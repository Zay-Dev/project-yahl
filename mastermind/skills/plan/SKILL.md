# plan

Use `/mastermind(plan, goal: …)`.

## Tool

```json
{
  "skill": "plan",
  "args": { "goal": "refactor auth module" }
}
```

Planning output is advisory; enforce work through **SKILL.yahl tasks** (steps), not free-form chat.
