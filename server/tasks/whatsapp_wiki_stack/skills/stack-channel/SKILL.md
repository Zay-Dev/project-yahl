# stack-channel

Merge a pending WhatsApp inbox window into wiki pages.

## overview

Replace or refresh the channel overview with cumulative understanding (participants, recurring topics, tone, open questions). Keep it concise.

## digests/{yyyy-mm-dd-HH}

One digest per stack run window: bullet summary of new messages, notable quotes (short), and new facts. Use the current time in Asia/Hong_Kong for the page segment when possible.
